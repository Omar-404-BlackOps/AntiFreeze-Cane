# AntiFreeze-Cane
AntiFreeze Cane is a Biomedical device designed to help Parkinson's patients bypass their most disabling symptom Freezing of Gait (FOG), by projecting a line laser beam on the ground as a visual cue, which helps the brain to initiate its next step, overcoming the freeze state almost immediately.
